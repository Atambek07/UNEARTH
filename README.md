# UNEARTH — Smart LFG-to-Energy & Computational Grid Simulator (MVP v0.2.2)

B2B/G2G платформа для Бишкекского санитарного полигона: моделирует добычу
свалочного газа (метана) из 20 млн т «старого тела» свалки, конверсию в
электроэнергию (off-grid, газопоршневые Jenbacher) и питание модульных
дата-центров (ИИ-серверы / Antminer S19 Pro) прямо на полигоне.

```
Старый мусор → Подземный метан → Электричество → Вычисления (ИИ / Майнинг)
                                    └──────────→ Green Tracker + карбоновые кредиты
```

## Что нового в v0.2.2

- **Живой рынок** (`market_data.py`): BTC — CoinGecko/Coinbase, хешрейт сети —
  mempool.space/blockchain.info, кэш 10 мин, честный откат на синтетику с пометкой
  источника. Рента GPU — справочная константа (публичного API нет).
- **Упреждающий балансировщик** (`POST /api/optimize/path`): динамическое
  программирование на 12+ месяцев с сезонным резервом, стоимостью переключений
  и помесячным путём BTC. Сравнение с наивным greedy в ответе.
- **Карбоновый модуль** (`POST /api/carbon`): кредиты по логике CDM ACM0001 —
  буфер 20 %, лаг верификации 12 мес, P10/P50/P90 цены, NPV с затратами на
  валидацию/верификацию/мониторинг.
- **Сценарии в БД** (`/api/scenarios`): SQLite по умолчанию, PostgreSQL через
  `UNEARTH_DB_URL`; сохранение прогонов и сравнение метрик с указанием лучшего.
- **Фискальный блок КР** в `/api/finance`: режимы `none`, `kr_general`, `kr_htp`
  (ПВТ) по годам — упрощённая модель, не налоговая консультация.
- **Налоги и валюта (v0.2.1)**: тариф майнинга 6.06 сома/кВт·ч по курсу,
  режим `kz_aifc` (Astana Hub, Казахстан) для сравнения, `POST /api/fiscal/compare`
  и валютный блок `POST /api/currency` (конвертация, репатриация, хедж).
- **Риск постоянного представительства (v0.2.2)**: `pe_risk_share` (50 % по умолчанию)
  облагает долю прибыли КЗ-юрлица в КР; зачёт иностранного налога не моделируется.
- **Полный payload сценариев (v0.2.2)**: сохраняются все секции результата —
  загрузка восстанавливает графики без пересчёта.

## Запуск

### Backend (FastAPI + ML)

```powershell
cd D:\UNEARTH\backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

- Swagger: http://localhost:8000/docs
- Проверка: `GET http://localhost:8000/api/health`
- Тесты: `python -m pytest tests -q` (71 тест)

Опциональные переменные окружения:

| Переменная | Назначение |
|---|---|
| `UNEARTH_DB_PATH` | путь к файлу SQLite (по умолчанию `backend/data/unearth.db`) |
| `UNEARTH_DB_URL` | PostgreSQL DSN; требует `pip install "psycopg[binary]"` |

### Frontend (React + Vite + Tailwind)

```powershell
cd D:\UNEARTH\frontend
npm install
npm run dev            # http://localhost:5173, /api проксируется на :8000
npm run build          # прод-сборка (tsc strict + vite build)
```

Дашборд сам запускает симуляцию дефолтами Бишкека; кнопка «Запустить симуляцию»
повторяет прогон с текущими параметрами. Порядок запросов: прогноз + рынок →
балансировщик/план/обслуживание/карбон/сектора → финансы.

## Модули

### Модуль 1 — ML-ядро прогнозирования (`/api/forecast`)

1. **Физика (LandGEM, EPA)**: `Q(t) = Σ k·L0·Mi·exp(-k·age)` по когортам.
   20 млн т накопленных ТБО (равномерно за 54 года), приток 350–400 тыс. т/год
   (стационарный вклад ≈ L0·M/12 в месяц), L0 70–80 м³/т, k 0.02–0.04 1/год,
   1 м³ CH₄ ≈ 3.5 кВт·ч × отбор газа × готовность ГПУ.
2. **ML-сезонность**: 48 мес «наблюдений» (seed), MA-12-декомпозиция, сезонные
   индексы и AR(1)-остатки, 95 % CI. Осенний пик бахчевых: +18 % к генерации,
   ×2.3 к волатильности. Prophet — опционально, с автоматическим откатом.

### Модуль 2 — Smart Grid, обслуживание, финансы

1. **Балансировщик** (`/api/optimize`): derate по качеству газа, маржа на кВт·день,
   жадное заполнение, лимит рынка GPU 1000, лестница отключений.
2. **Упреждающий план** (`/api/optimize/path`): DP по месяцам — «greedy» или
   «удержать прошлый план»; резерв 4→16 % по влажности следующего месяца;
   стоимость переключений (20 $/ASIC, 150 $/ИИ-сервер); путь BTC.
3. **Обслуживание** (`/api/maintenance`): износ `0.35·(H₂S/25)^1.35 %/мес`,
   health/RUL/риск, ресурс скрубберов, OPEX по статьям.
4. **Финансы** (`/api/finance`): CAPEX по статьям, 400 траекторий Монте-Карло,
   P10/P50/P90, дисконтированный поток (WACC 10 %), окупаемость, IRR,
   CO₂ и Фонд озеленения (5 % прибыли), фискальный блок КР.

### Карбон и сектора

- **Карбон** (`/api/carbon`): ER = CH₄ × GWP-28; буфер 20 %; лаг 12 мес;
  NPV при ценах 8/15/25 $/т; затраты на валидацию, верификацию, мониторинг.
- **Сектора** (`/api/sectors`): 48 секторов 6×8, статусы `green`/`amber`/`red`/
  `depleted`, RF-прогноз нестабильности.

## Константы и допущения

«Физические» числа — из проектного досье UNEARTH (ЕБРР/Мэрия/EPA): 20 млн т,
350–400 тыс. т/год, L0 70–80 м³/т, k 0.02–0.04, CH₄ 50–55 %, 3.5 кВт·ч/м³,
Antminer S19 Pro 3.25 кВт, ИИ-сервер 1.5 кВт, амортизация 1.5–2 ¢/кВт·ч.
Экономические параметры (CAPEX, GWP-28, рента GPU 2 $/GPU·ч, курс BTC 65 000 $,
стоимость переключений, карбоновые ставки, налоги КР) — `ASSUMPTION` в
`backend/app/config.py`, переопределяются параметрами API.

## Известные ограничения MVP

- Рента GPU — справочная константа: публичного бесплатного API аренды нет.
- Живой рынок зависит от внешних API; при сбое — синтетика с пометкой в `notes`.
- Фискальная модель и карбон — упрощённые: не налоговая консультация и не
  верифицированный выпуск кредитов (нужны регистрация, валидация, MRV).
- Astana Hub — режим Казахстана, а не КР; риск ПП учтён через `pe_risk_share`,
  но зачёт иностранного налога не моделируется.
- Требование репатриации валютной выручки именно для КР не подтверждено
  первоисточниками — валютный блок считает заданные сценарии, а не обязанность.
- Сценарии хранят полный payload (графики восстанавливаются без пересчёта);
  дайджест метрик используется только для сравнения.
- Prophet — опциональная зависимость (cmdstan); встроенная модель работает без него.
